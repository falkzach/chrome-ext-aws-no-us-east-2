# RELEASES

## v1.1.0
* Added A new user interface with popup and options configuration.
* Added toggle to disable rewrites.
* Added ACL-like rewrite rule language with default rules maintain `us-east-2` to `us-east-1` behavior.
* Added cycle detection to the rewrite engine to prevent infinite loops and improve reliability.
* Added Region Group toggles.
* Added a state-aware save mechanism for configuration.
* Added system aware dark mode theme.

* Rewrite aws region `us-east-2` to `us-east-1`.
