AWS Region Rewriter

Route console regions intentionally.

Build first-match ACLs for AWS Console region redirects. Put specific rules first, broader wildcard rules later, and keep * -> * as the safe default.

Rewrite Rules

Rules are evaluated top to bottom. Shadowed rules are rejected before saving.

Rule Guide

Valid Patterns

us-east-2 -> us-east-1 us-* -> us-east-1 us-west-* -> us-east-1 * -> us-east-1 * -> *

Constraints

Source wildcards are prefix-only. Destinations must be exact regions, except * is allowed only for pass-through defaults.
