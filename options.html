Valid Patterns

us-east-2 -> us-east-1 us-* -> us-east-1 us-west-* -> us-east-1 * -> us-east-1 * -> *

Constraints

Source wildcards are prefix-only. Destinations must be exact regions, except * is allowed only for pass-through defaults.
